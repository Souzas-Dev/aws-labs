# AWS Labs — Laboratórios Práticos de Cloud Computing

Este repositório reúne meus laboratórios práticos de
computação em nuvem, com foco nos serviços da Amazon
Web Services (AWS).

Meu objetivo é desenvolver conhecimentos em infraestrutura,
redes, segurança, automação e administração de ambientes
Cloud, registrando minha evolução técnica.

## Laboratórios

| Lab | Serviço | Descrição | Status |
|-----|---------|-----------|--------|
| 01 | Amazon EC2 | Provisionamento, segurança e monitoramento | Parcialmente concluído |

### Lab 01 — Amazon EC2

Neste laboratório, configurei uma instância Amazon EC2
com Amazon Linux 2023, VPC, Security Group, Amazon EBS
e automação utilizando Bash e User Data.

Também realizei verificações de integridade e testes
de conectividade HTTP.

O laboratório foi realizado no ambiente educacional
da Escola da Nuvem, disponibilizado pelo Vocareum.

**[Acessar documentação completa do Lab EC2](EC2/README.md)**
